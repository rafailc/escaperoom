# Για να τρέξετε την εφαρμογή θα χρειαστείτε το XAMPP
# Πως να την τρέξετε:
## Αρχικά κατεβάστε τον φάκελο "escaperoom" και επικολήστε το στο: "\xampp\htdocs"
1) Ανοίξτε το xampp και ενεργοποιείστε το Apache kai MySQL.
2) Πηγαίντε στο http://localhost/phpmyadmin/index.php.
3) Πηγαίνετε στην "Εισαγωγη" και μετα  στο "Αρχείο για εισαγωγή"->"choose  file"  και βαλτε το "profile.sql" που βρισκετε στο "C:\xampp\htdocs\escaperoom"  και μετά "εισαγωγη",
θα πρεπει να φτιαχτει το database με ονομα "profiles" και μεσα τα tables "reservations" και "users".
4) τελος πηγαιντε στο "http://localhost/escaperoom/home.html" για να δειτε την εφαρμογη.
