# Για να τρέξετε την εφαρμογή θα χρειαστείτε το XAMPP
# Πως να την τρέξετε:
## Αρχικά κατεβάστε τον φάκελο "escaperoom3" και επικολήστε το στο: "\xampp\htdocs"
1) Ανοίξτε το xampp και ενεργοποιείστε το Apache kai MySQL.
2) Πηγαίντε στο http://localhost/phpmyadmin/index.php.
3) Πηγαίνετε στην "Εισαγωγη" και μετα  στο "Αρχείο για εισαγωγή"->"choose  file"  και βαλτε το "profile.sql" που βρισκετε στο "C:\xampp\htdocs\escaperoom3"  και μετά "εισαγωγη",
θα πρεπει να έχει φτιαχτει το database με ονομα "profiles" και μεσα τα tables "reservations" και "users" και "rooms".
4) τελος πηγαιντε στο "http://localhost/escaperoom3/home.html" για να δειτε την εφαρμογη.

---
- τα rooms μπαινουν στο database στο table "rooms" αλλα οι φωτογραφιες πρεπει να αποθηκευοντε στο φακελο"rooms" και στο table column "photos" να αποθηκευτουν τα ονοματα των φωτογραφιων ως"name.png"
- μπορειτε να μπειτε ως admin: στο login page "username"="admin" κωδικος="12345678"   και στα δωματια page θα υπαρχουν 2 κουμπια πανω δεξια  "Επεξεργασία Δωματίων" και "Κρατήσεις".
Στο "Επεξεργασία Δωματίων" page μπορειτε να κανετε create room, update room,delete room και να δειτε ολα τα δωματια.
Στις "Κρατήσεις" μπορειτε να δειτε τις κρατησεις που εχουν κανει οι χρηστες.
